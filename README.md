# MCS — MSc in Cybersecurity

Coursework repository for the **MSc in Cybersecurity** at the **University of Minho**, 2026/27.

Everything is organised as `year-N/semester-N/<course>/`, so new semesters are just new
folders alongside the existing ones.

## Layout

```text
year-1/
└── semester-1/
    ├── SD/    Data Security
    ├── SR/    Network Security
    └── SSC/   Computer Systems Security
```

Every course follows the same convention (not every course uses every folder):

| Folder         | Contents                                                    |
| -------------- | ----------------------------------------------------------- |
| `theory/`      | Lecture slides and theoretical material (PDF)                |
| `assignments/` | Graded assignments: statement, code, report                  |
| `labs/`        | Practical lab work: statements, code, logs, notes            |
| `guides/`      | Lab guides handed out by the course                          |
| `reports/`     | Written deliverables (sources + compiled PDF)                |
| *submodule*    | Larger project work (own git repo, linked in place)          |

Each course has its own `README.md` with the deliverables, dates and build instructions.

## Notes

- **Theoretical PDFs** live in each course's `theory/` folder, mirrored from eLearning with
  [`tools/elearning-sync`](tools/elearning-sync) — see its README.
- **`year-1/semester-1/SD/sd2627` is a git submodule** pointing at
  [marcosevegrand/sd2627](https://github.com/marcosevegrand/sd2627). Clone with:

  ```sh
  git clone --recurse-submodules <this-repo>
  ```

  or, in an existing clone, `git submodule update --init --recursive`.
- Compiled PDFs are committed on purpose (they are the deliverables); LaTeX/Typst
  build artefacts and `.DS_Store` are ignored.
- Lecture PDFs can be pulled from eLearning with
  [`tools/elearning-sync`](tools/elearning-sync) — see its README. It needs a session
  cookie, because UMinho's WAF blocks automated SSO logins.
- `SD/assignments/05-openssl` contains a throwaway self-signed key pair generated by its
  `Makefile`. It is demo material only — never reuse it.
